# firstOrCreate()

## 概要

データがあるか確認してから保存する処理。

## サンプル

```php
<?php
$user = User::firstOrCreate(
    ['email' => $email],
    ['name' => $name]
);
```

- emailで検索
- あればそのレコードを返す
- なければemailとnameで作成する

=> `$user`にはUserモデルのインスタンスが格納

## updateOrCreate()

もし存在したときに更新したいならこちら。

```php
<?php
$user = User::updateOrCreate(
    ['email' => $email],
    ['name' => $name]
);
```

- 検索 -> 存在する -> 更新
- 検索 -> 存在しない -> 新規作成

=> いずれにしろ、検索条件は第1引数

=> 第2引数は更新・作成用

=> `Model`クラスにこれらのメソッドは用意されている

## サンプル2

```php
<?php
Product::updateOrCreate(
    ['code' => $item['code']],
    [
        'name' => $item['name'],
        'price' => $item['price'],
    ]
);
```

- 商品コードで検索
- あれば更新
- なければ作成
