# AlpineとLivewire

## 概要

Alpine.jsとLivewire連携メモ。

## サンプルコード

```blade
@keydown.escape.window="$wire.closeDeleteModal()"
@click.self="$wire.closeDeleteModal()"
```

- `@keydown.escape.window`
- `@click.self`

=> Alpine.jsの構文

- `$wire.closeDeleteModal()`

=> LivewireのメソッドをJavaScritpから呼び出している

つまり、`Alpine.js` -> `Livewire`の流れ。

## @とは？

これはAlpine.jsの省略記法。

正式には:

```blade
x-on:click=""
```

両者は同じ:

- `@click.self=""`
- `x-on:click.self=""`

## $wireとは？

LivewireコンポーネントをJavaScritpから操作するためのオブジェクト。

`$wire`はJavaScritpから見たLivewireコンポーネントそのものと思えばOK。
