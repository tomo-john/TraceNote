# HTTPステータスコード

## 概要

Webサーバーが、ブラウザやアプリからのHTTPリクエストに対して、処理結果を伝える3桁の数字。

## 主な分類

| コード | 意味                   | 代表例                                                          |
| ------ | ---------------------- | --------------------------------------------------------------- |
| 1xx    | 情報                   | 100 Continue                                                    |
| 2xx    | 成功                   | 200 OK                                                          |
| 3xx    | リダイレクト           | 301 Moved Permanently、302 Found                                |
| 4xx    | クライアント側のエラー | 400 Bad Request、401 Unauthorized、403 Forbidden、404 Not Found |
| 5xx    | サーバー側のエラー     | 500 Internal Server Error、503 Service Unavailable              |

## よく出るやつ


| コード | 意味                  | Laravelでよくあるケース       |
| ------ | --------------------- | ----------------------------- |
| 200    | OK                    | 正常にページ・データを返した  |
| 201    | Created               | POSTでデータ作成成功          |
| 204    | No Content            | 成功したが返す内容がない      |
| 301    | 恒久的リダイレクト    | URLが完全に移転               |
| 302    | 一時的リダイレクト    | `redirect()` など             |
| 304    | Not Modified          | キャッシュを使ってよい        |
| 400    | Bad Request           | リクエスト自体がおかしい      |
| 401    | Unauthorized          | 認証されていない              |
| 403    | Forbidden             | 認証はされているが権限がない  |
| 404    | Not Found             | 対象が存在しない              |
| 405    | Method Not Allowed    | HTTPメソッドが違う            |
| 419    | Page Expired          | LaravelでCSRFトークン切れなど |
| 422    | Unprocessable Content | バリデーションエラー          |
| 429    | Too Many Requests     | リクエストしすぎ              |
| 500    | Internal Server Error | サーバー側の予期しないエラー  |
| 503    | Service Unavailable   | メンテナンス中など            |

## UIメモ

- 404, 403のオリジナル化(Topに戻れるなど)
- 419, 500も一度開発段階で経験しておく
