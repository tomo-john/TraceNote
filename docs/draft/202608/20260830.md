# Symfony

## 概要

PHPでWebアプリケーションを作るためのフレームワーク/コンポーネント群。

## SymfonyとLaravel

Symfonyは単純にLaravelとは別のWebフレームワークというだけでなく、再利用可能なPHPコンポーネント群を提供しているプロジェクト。

LaravelはSymfonyの部品をいくつか利用している。

## 今回

PHP 8.3.6対応時に遭遇。

`composer.json`を編集し、`versions : v8.0.8 => v7.4.18`に変更した。

確認コマンド: `composer show symfony/http-foundation`

## symfony/http-foundationとは？

ざっくり: PHPのHTTPリクエスト／レスポンスを扱いやすくするためのライブラリ

LaravelのHTTP処理の土台の一部にSymfonyのコンポーネントがある。

イメージ:

```bash
Laravelアプリ => Symfonyの各種コンポーネント => PHP
```
