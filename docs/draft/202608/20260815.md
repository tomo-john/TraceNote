# Laravelエラー画面

## 概要

仕組みの確認 -> 自作UIは？ -> 発生させて確認

## 仕組み

`abort(404)`や`abort(403)`をアプリの処理中に発生すると、

LaravelがそのHTTPステータスに応じたエラーレスポンスを作ってくれる。

そして対応するBladeを用意すると、自分で画面をカスタマイズすることもできる。

たとえば、404に対応するエラーページをカスタマイズするには、

`resources/views/errors/404.blade.php`を作成する。

=> `errors`ディレクトリに置くBladeファイルはHTTPステータスコードと一致するファイル名にする。

## カスタムエラー画面を作る時の注意点

エラー画面では、通常のアプリ画面と完全に同じ依存関係を持たせ過ぎない方がいい。

エラー画面によって発生したエラー画面内の処理でまたエラー画面が起きると悲しい...

- シンプル
- 依存する処理が少ない
- 最低限のリンクだけ
- 既存のCSS/UIを利用する場合も複雑にしすぎない
