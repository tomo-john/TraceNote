# Composer 基礎まとめ

## 1. Composerとは

**PHPの依存関係管理ツール**。

LaravelなどのPHPプロジェクトで使用するパッケージを管理し、必要なパッケージやその依存関係を自動的に解決してくれる。

```text
自分のアプリ
  ↓
Laravel
  ↓
Symfony / Carbon / Monolog ...
  ↓
さらに必要なパッケージ
```

---

## 2. Composerの主な役割

* PHPパッケージのインストール・削除
* パッケージのバージョン管理
* パッケージ同士の依存関係を解決
* PHPクラスのオートロード

---

## 3. composer.json

プロジェクトが**「何を必要としているか」**を定義するファイル。

```json
{
    "require": {
        "php": "^8.3",
        "laravel/framework": "^12.0",
        "livewire/livewire": "^4.0"
    }
}
```

### ポイント

```text
composer.json
    ↓
「Laravel 12系が必要」
「PHP 8.3以上が必要」
```

という**要求・条件を宣言する**。

---

## 4. composer.lock

Composerが依存関係を解決した結果、

> **「実際にこのバージョンを使う」**

という情報を記録するファイル。

```text
composer.json
    ↓
バージョン条件を確認
    ↓
Composerが依存関係を解決
    ↓
composer.lock
    ↓
実際のバージョンが確定
```

チーム開発では、基本的に `composer.lock` もGit管理する。

---

## 5. composer install

```bash
composer install
```

基本的には **`composer.lock` に記録されたバージョンを使ってインストールする**。

```text
composer.lock
    ↓
指定されたバージョン
    ↓
vendor/
```

そのため、開発環境と本番環境で同じ依存関係を再現しやすい。

---

## 6. composer update

```bash
composer update
```

`composer.json` の条件をもとに、**依存関係を再計算する**。

その結果、

```text
composer.json
    ↓
依存関係を再計算
    ↓
composer.lockを更新
    ↓
vendor/を更新
```

となる。

### installとの違い

| コマンド               | 主な役割              |
| ------------------ | ----------------- |
| `composer install` | lockの内容をインストール    |
| `composer update`  | 依存関係を再計算してlockを更新 |

---

## 7. vendor/

Composerがインストールしたパッケージが入るディレクトリ。

```text
vendor/
├── laravel/
├── symfony/
├── livewire/
└── ...
```

`composer.json` と `composer.lock` があれば、

```bash
composer install
```

で再生成できるため、通常はGit管理しない。

---

## 8. オートロード

Composerには**オートローダー**がある。

Laravelでは、

```php
require __DIR__.'/../vendor/autoload.php';
```

などによってComposerのオートロード機能を読み込む。

そのため、

```php
use Illuminate\Support\Facades\Auth;
```

のように、必要なクラスを自分で1つずつ `require` しなくても利用できる。

---

## 9. バージョン指定

例えば、

```json
"laravel/framework": "^12.0"
```

の `^` は、互換性を保てる範囲でバージョンアップを許可するための記法。

Composerではこのような**バージョン制約**を使って、インストール可能なバージョンを決定する。

---

## 10. Laravel開発での流れ

### パッケージを追加

```bash
composer require パッケージ名
```

↓

### composer.json / composer.lock が更新される

↓

### Gitにコミット

```text
composer.json
composer.lock
```

↓

### 本番サーバーで

```bash
composer install
```

↓

### vendor/を構築

```text
Laravelアプリ
    ↓
vendor/
```

---

# 🐶 最重要ポイント

まずはこの4つをセットで覚える。

```text
composer.json
    ↓
「必要なもの・条件」

composer.lock
    ↓
「実際に使うバージョン」

vendor/
    ↓
「インストールされたパッケージ」

Composer
    ↓
「これらを管理・解決する仕組み」
```

そして、

```bash
composer install
```

= **決まった依存関係をインストール**

```bash
composer update
```

= **依存関係を再計算して更新**

と覚えるとよい
