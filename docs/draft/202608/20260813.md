# Gate

## 概要

特定のModelに紐づかない認可ルールを扱えるもの。

## Policyとの違い

Policyは特定のModelに対する認可ルールをまとめるクラス。

Gateは特定のModelには紐づかず、「このユーザーは管理者か？」みたいなルール。

| 項目             | Policy                  | Gate                  |
| ---------------- | ----------------------- | --------------------- |
| 主な対象         | 特定のModel             | 任意の処理・権限      |
| 認可ルールの整理 | Modelごとにまとめる     | Gate名ごとに定義      |
| 向いているもの   | CRUDなどModel中心の認可 | Modelに依存しない認可 |

## Gateの凡例

「管理者だけアクセスできる管理画面」など。

Gateの定義は`AppServiceProvider`などでGateを定義できる。

```php
<?php
use Illuminate\Support\Facades\Gate;

public function boot(): void
{
    Gate::define('access-admin', function (User $user) {
        return $user->is_admin;
    });
}
```

これで、`access-admin -> $user->is_admin === true?`という認可ルールができる。

RouteでGateを使う:

```php
<?php
Route::get('/admin', AdminDashboard::class)
    ->middleware('auth')
    ->can('access-admin');
```

- Gateはルーティングの段階でも使える
- 認可に失敗したら403エラー

Controllerでも使える:

```php
<?php
public function index()
{
    Gate::authorize('access-admin');

    return view('admin.index');
}
```

Livewireでも使える:

```php
<?php
use Illuminate\Support\Facades\Gate;

public function mount(): void
{
    Gate::authorize('access-admin');
}
```
