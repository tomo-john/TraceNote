# belongsTo

## 概要

1対多(逆) / 属する

## TraceNoteコード抜粋

Traceモデル:

```php
<?php
use Illuminate\Database\Eloquent\Relations\HasMany;

    public function outgoingRelations() :HasMany
    {
        return $this->HasMany(TraceRelation::class, 'from_trace_id');
    }

    public function incomingRelations() :HasMany
    {
        return $this->HasMany(TraceRelation::class, 'to_trace_id');
    }
```

TraceRelationモデル:

```php
<?php
use Illuminate\Database\Eloquent\Relations\BelongsTo;

    public function fromTrace(): BelongsTo
    {
        return $this->belongsTo(Trace::class, 'from_trace_id');
    }

    public function toTrace(): BelongsTo
    {
        return $this->belongsTo(Trace::class, 'to_trace_id');
    }
```

## 多対多は一旦忘れる

- Trace -- hasMany --> TraceRelation
- TraceRelation -- belongsTo --> Trace

TraceとTraceRelationの間だけ見ると、普通の1対多 / 多対1と見える。

## メソッドの第二引数

普通の`belongsTo`なら、`return $this->belongsTo(User:class);`みたいに第二引数はない。

これはLaravelが規約から、`user_id`という外部キーを推測することができるから。

TraceNoteでの中間テーブルである`trace_relations`は`from_trace_id`, `to_trace_id`という2つの外部キーがある。

=> しかもどちらも`traces.id`を指している

=> Laravelにどっちのカラム使うの？と聞かれてしまう

なので、`$this->belongsTo(Trace::class, 'from_trace_id');`第二引数で明示してあげる必要がある。
