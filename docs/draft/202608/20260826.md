# withPivot()

## 概要

多対多リレーションにおいて、中間テーブルに存在するカラムを取得するメソッド。

## TraceNoteでの多対多(Trace - Tag)

モデル:
- Trace
- Tag

Traceは複数のTagを持つことができ、Tagは複数のTraceに紐づく。

=> 多対多の関係

中間テーブル: `tag_trace`

=> 関連するモデル(Trace, Tag)名のアルファベット順に基づいて作成

```
tag_trace:
    trace_id
    tag_id
```

## マイグレーションファイル

```php
<?php
Schema::create('tag_trace', function (Blueprint $table) {
    // 外部キー制約の設定（元データが消えた時に中間テーブルのレコードも自動削除）
    $table->foreignId('trace_id')->constrained()->cascadeOnDelete();
    $table->foreignId('tag_id')->constrained()->cascadeOnDelete();
    
    // 重複登録の防止（同じTraceとTagの組み合わせを1つだけに制限する場合）
    $table->primary(['trace_id', 'tag_id']);
});
```

## belongsToMany()

```php
<?php
use Illuminate\Database\Eloquent\Relations\BelongsToMany;

// Trace
class Trace extends Model
{
    public function tags(): BelongsToMany
    {
        return $this->belongsToMany(Tag::class);
    }
}

// Tag
class Tag extends Model
{
    public function traces(): BelongsToMany
    {
        return $this->belongsToMany(Trace::class);
    }
}
```

Trace, Tagそれぞれのモデルにメソッドを定義してあげる。

これで多対多のリレーションはOK。

- 紐付け: `$trace->tags()->attach($tagId);`
- 解除: `$trace->tags()->detach($tagId);`
- 同期: `$trace->tags()->sync([1, 2, 3]);`
- 取得: `$trace->tags;`

## 中間テーブル(Pivot)

```php
<?php
> $tag->traces->first()->pivot

= Illuminate\Database\Eloquent\Relations\Pivot {#8683
    tag_id: 1,
    trace_id: 1,
  }
```

`pivot`は取得した関連モデルの中に自動的に生えてくるプロパティ。

PivotはEloquentの多対多(`belongsToMany()`)の中間テーブルを扱うための仕組み。

## withPivot()

例えば、中間テーブルがこうだとする。

```
trace_tag

trace_id | tag_id | importance
---------|--------|-----------
10       | 1      | high
10       | 2      | low
```

リレーション:

```php
<?php
public function tags(): BelongsToMany
{
    return $this->belongsToMany(Tag::class)
        ->withPivot('importance');
}
```

こうすると、`$tags = $trace->tags;`で取得したTagから、

`$tag->pivot->importance`とアクセスすることができる。

イメージ:

```
Trace #10
   │
   │ belongsToMany
   ▼
Tag #1
   │
   └── pivot
         └── importance = high
```
