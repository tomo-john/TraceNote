# Blade変数名

## 概要

Bladeの`@props`では、ハイフン付きの名前はPHP変数として使用できない

## NG

`x-trace.relation-card`:

```blade
@props([
    'traces',
    'relation-type',
])

{{ $relation-type->label() }}
```

これはPHPでは、`$relation - type`という引き算として解釈されてします。

## OK

```blade
@props([
    'traces',
    'relationType',
])
```

呼び出し側:

```blade
<x-trace.relation-card
    :traces="$this->prerequisiteTraces"
    :relation-type="App\Enums\TraceRelationType::PREREQUISITE"
/>
```

呼び出し側の属性はケバブケースのままでOK。

コンポーネント側では、`relationType`として使用する。

Laravelは`relation-type` -> `relationType`へ自動で変換してくれる。
