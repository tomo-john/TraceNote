# TraceRelation振り返り3

## 概要

少し具体的に

## Step1

```bash
$trace = Trace::find(10);

trace_relations

| id | from_trace_id | to_trace_id |
| -- | ------------- | ----------- |
| 1  | 10            | 20          |
| 2  | 10            | 30          |

$relations = $trace->outgoingRelations;
```

outgoingRelationsはfrom_trace_id = 10を探す。

`$relations`には、2件の`TraceRelations`モデルが入ったCollectionが入る。


## Step2

```php
<?php
foreach ($relations as $relation) {
    // ...
}
```

1回目のループで:

```bash
$relation

id = 1
from_trace_id = 10
to_trace_id = 20
```

が入っていたとする。

- `$relation->fromTrace`はtrace_id = 10のTraceモデル
- `$relation->toTrace`はTrace_id = 20のTraceモデル

## Step3

traces:

```bash
id | title
---|---------
10 | Laravel
20 | Eloquent
30 | Livewire

trace_relations:

```bash
id | from_trace_id | to_trace_id | relation_type
---|---------------|-------------|--------------
1  | 10            | 20          | related
2  | 30            | 10          | related
```

図にすると:

```
Trace #10 ---> Trace #20
Trace #30 ---> Trace #10
```

```
$trace = Trace::find(10);
```

### 1

Traceモデルの:

```php
<?php
public function incomingRelations(): HasMany
{
    return $this->hasMany(TraceRelation::class, 'to_trace_id');
}
```

を使って、

```php
<?php
$relations = $trace->incomingRelations;
```

としたとき、

`$relations`には、`TraceRelations`が1件入る。

=> `to_trace_id = 10`の行。

`incomingRelations()`のメソッドでは、外部参照キーのtrace_idをto_trace_idとしているため。

今回の場合、trace_id = 10($trace)の為、trace_relationsテーブルのto_trace_id = 10の行が1つ$relationsには入る。

この時:

- `$relation->fromTrace`: trace_id = 30のTraceモデルのインスタンス
- `$relation->toTrace`: trace_id = 10のTraceモデルのインスタンス

をそれぞれ取得できる。

なので、`Trace #10`から見て、自分に向かってくる矢印の`Trace #30`を取得するとき、

`$relation->fromTrace`を使用する。

`fromTrace`では、外部参照キーのtrace_idに`from_trace_id`を指定しているため。
