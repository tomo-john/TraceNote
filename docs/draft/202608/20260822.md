# TraceRelation振り返り2

## 概要

outgoingRelations()

## HasMany

```php
<?php
public function outgoingRelations(): HasMany
{
    return $this->hasMany(TraceRelation::class, 'from_trace_id');
}
```

`outgoingRelations()` <- メソッド

TraceとTraceRelationのリレーション定義であり、`HasMany`リレーションオブジェクトを返す。

`$trace->outgoingRelations()`は実際にリレーション先のTraceRelationを取得した結果。

複数件なので、結果は基本的にCollectionになる。

outgoingRelations は、from_trace_id が現在のTraceのIDと一致する複数の TraceRelation を取得するためのHasManyリレーション。

そのリレーションに relation_type などの条件を追加して取得すると、該当する複数の TraceRelation がCollectionとして取得できる。

## TraceRelation -> Trace

```php
<?php
public function fromTrace(): BelongsTo
{
    return $this->belongsTo(Trace::class, 'from_trace_id');
}

public function toTrace(): BelongsTo
{
    return $this->belongsTo(Trace::class, 'to_trace_id');
}
```

```bash
TraceRelation:

| id | from_trace_id | to_trace_id |
| -- | ------------- | ----------- |
| 1  | 10            | 20          |
```

この1行を`$relation`とする。

`$relation->fromTrace()`は`from_trace_id = 10`を使って、`traces.id = 10`のTraceを取得する。

TraceRelationには from_trace_id と to_trace_id という2つの外部キーがあり、どちらも traces.id を参照している。

そのためTraceRelationからは、from側のTraceとto側のTraceという、2つのbelongsToリレーションを定義している。
