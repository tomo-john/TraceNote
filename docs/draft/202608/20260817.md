# Laravelデフォルトのエラー画面

## 概要

Laravelがパッケージ内部に持っているデフォルトのエラーページテンプレートを、自分のアプリ側にコピー。

## artisanコマンド

```bash
php artisan vendor:publish --tag=laravel-errors
```

Laravelがパッケージ内部に持っているデフォルトのエラーページテンプレートを自分のアプリ側にコピーするコマンド。

## vender:publish

`vendor:publish`はコピーして公開する。

LaravelやComposerパッケージが持っている、

- 設定ファイル
- Blade
- CSS
- 画像
- Migration

などを、自分のアプリで編集できる場所にコピーするための仕組み。

## --tag=laravel-errors は何？

`laravel-errors`という名前が付けられた公開対象をコピーしてね。とう指定。

`php artisan vendor:publish`だけだと、何を公開するの？となる。

なので、`--tag=laravel-errors`を指定して、Laravelのエラーページだけをお願いしている。

## 実行すると

`resources/views/errors/`以下に、`401.blade.php`, `402.blade.php`...のようにファイルが配置される。

このファイルを自由に編集してオリジナルのエラー画面を作成することができる。

## 手動で作るのと何が違う？

`resources/views/errors/404.blade.php`を自分で最初から作ってもいい。

=> 0から自分で作成

=> ファイルがあれば、Laravelがこれを表示してくれる

=> `php artisan vendor:publish --tag=laravel-errors`は必須ではない
