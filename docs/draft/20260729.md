# withCount()

## 概要

関連モデルの件数を取得して、`xx_count`という属性を追加してくれるメソッド。

## サンプル

```php
<?php
$tags = Tag::withCount('traces')->get();
```

とすると、各Tagに`$tag->traces_count`という属性が自動で追加される。

## Livewireで使用

```php
<?php
protected function refreshTags(): void
{
    $this->tags = auth()->user()
        ->tags()
        ->withCount('traces')
        ->get();
}
```

=> Blade側では`{{ $tag->traces_count }}`で使用できる
