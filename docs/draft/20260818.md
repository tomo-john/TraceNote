# Trace Relation 復習

## 概要

TraceNoteにおける、Trace同士の関連付け(復習・殴り書き)

## A -> B

```bash
Trace A
Trace B

があった時、Trace A -> Trace B と紐づけたときのこの「 -> 」とは何なのか？
```

### A -> B は所有関係ではない

AがBを所有しているのではなく、AとBという2つのTraceに関連性があるという意味。

- AとBは対等な存在
- A -> B = B -> A

## TraceNoteでのドメインルール

A -> Bと紐づけた時点で、AとBのTraceは関連しているので、B -> Aの紐づけはできない。

AとBの関連は1つだけ存在するというルールを設けている。

## 矢印の意味とは何なのか

```bash
A -> B = B ->A ならば、A - B でいいのではないか？
矢印に何の意味があるのか？
```

### TraceNoteにおける関連性の意味

TraceNoteでは関連性のタイプに以下の3つを定義した。(MVP時点)

- 前提知識
- 子知識
- 関連知識

これまでの、`A -> B = B -> A`は(単純な)関連知識。

### 具体例

| id  | 内容       |
| --- | ---------- |
| 1   | PHP Array  |
| 2   | Collection |
| 3   | map()      |
| 4   | fillter()  |

みたいなtracesテーブルの場合:

- PHP Array -> Collection : 前提知識
- Collection -> map() : 子知識
- map() - fillter() : 関連

これらは全部Trace同士が関連しているけど、関連の意味が違う。
