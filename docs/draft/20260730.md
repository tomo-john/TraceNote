# Livewireプロパティ

## 概要

通常プロパティとcomputedなど。

## 通常プロパティ(public property)

状態(state)を保持するための箱。

今このコンポーネントが覚えておくべき値。

```php
<?php
class UserForm extends Component
{
    public string $name = '';
    public string $email = '';

    public function save()
    {
        User::create([
            'name' => $this->name,
            'email' => $this->email,
        ]);
    }
}
```

これはフォーム入力値なのでプロパティが正解。

- ユーザーが入力する
- 入力途中の値を保持したい
- 保存処理で使う

```bash
ユーザー入力 -> public property -> 保存
```

## computed property

既存データから作れる値。

保存する必要がない、一時的な計算結果のイメージ。

```php
<?php
class Cart extends Component
{
    public array $items = [];

    public function getTotalProperty()
    {
        return collect($this->items)
            ->sum('price');
    }
}
```

```blade
合計金額：{{ $this->total }}
```

ここで、`$total`は保存していない。

```bash
商品A: 100円
商品B: 200円
...
合計: 300円
```

これは毎回計算できる。

## 判断基準

| 状況                       | プロパティ       |
| -------------------------- | ---------------- |
| ユーザーが入力する         | public property  |
| ボタン押下前の値を保持する | public property  |
| DB保存する値               | public property  |
| 他の値から計算できる       | computed         |
| 表示専用の値               | computed         |
| 並び替え後の一覧           | computed         |
| 件数表示                   | computed         |
| 合計金額                   | computed         |

## computed propertyの書き方

- `getXxxProperty()`は旧来からあるcomputedの書き方(命名規則)
- `#[Computed]`は Laravel Livewire 3以降の新しい書き方(属性)

`getXxxProperty()`:

```php
<?php
public function getTotalProperty()
{
    return $this->price * $this->quantity;
}
```

Livewireが、`get + Property`の形だと認識し、

Blade側で`$this->total`として使えるようにしてくれる。

`#[Computed]`:

```php
<?php
use Livewire\Attributes\Computed;

class Cart extends Component
{
    public $price = 100;
    public $quantity = 3;

    #[Computed]
    public function total()
    {
        return $this->price * $this->quantity;
    }
}
```
