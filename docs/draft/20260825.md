# trace_relations

## 概要

`trace_relations`の1行は単なる「つなぎ」でなく、1つの関連情報そのものを表している。

## 例

```
Trace A --> 前提知識という関連 --> Trace B

trace_relations:

from_trace_id = 10
to_trace_id   = 20
relation_type = prerequisite
```

この3つをまとめて、Trace#10とTrace#20の間には、prerequisiteという関係が存在する

という意味のある情報として扱っている。

=> なので、`TraceRelation`というモデルとした

=> `trace_relations`の1レコード自体を、独立したドメイン上の情報として扱いたかった

## 代替案

- `belongsToMany()`
- 中間テーブル(Pivot)
- `withPivot()`
- カスタムPivotモデル
