# Eloquent

## 概要

belongsToおさらいのためのおさらい。

## Eloquentとは？

Eloquent = LaravelでDBをPHPオブジェクトとして扱うためのORM。

=> Modelを通して、テーブルを扱うことができる

### ORM

ORM = Object-Relational Mapping

- Object: PHPのオブジェクト
- Relational: リレーショナルDB
- Mapping: 対応付ける

=> DBのデータとプログラムのオブジェクトを対応付ける仕組み

## artisanコマンド

Model作成:

```bash
php artisan make:model Dog
```

オプション:

- `-c`: Controller
- `-m`: Migration
- `-f`: Factory
- `-s`: Seeder

Modelの確認:

```bahs
php artisan model:show Dog
```

=> カラムやリレーションが確認できる

## テーブル名規約

モデルクラス名の複数形のスネークケースがテーブル名となる。(明示しない場合)

- Dog : dogs
- Trace : traces
- TraceRelation : trace_relations
