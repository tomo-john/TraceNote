# エラー画面のカスタマイズ

## 概要

公式ドキュメントの内容をかみ砕く。

## $exeptionとは？

> Symfony\Component\HttpKernel\Exception\HttpExceptionによって発生したインスタンスは、
> 変数abortとしてビューに渡されます$exception。

Blade側で変数`$exeption`が利用できる。

```blade
<h2>{{ $exception->getMessage() }}</h2>
```

## $exeptionには何が入っている？

発生したHTTP例外のオブジェクトそのものが入っている。

エラーの詳細情報を全部持った専用の変数ではない。

例えば、`abort(404, 'エラー');`のようにメッセージを渡した場合、

Blade側では`<p>{{ $exception->getMessage() }}</p>`のようにメッセージを表示できる。

`$exception->getStatusCode()`ではステータスコードを表示することも可能。

## abort()の引数は3つ

```php
<?php
abort(
    int $code,
    string $message = '',
    array $headers = []
);
```
