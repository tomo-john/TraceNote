# C++

## 概要

どんなプログラミング言語なのか？

## C++とは

C言語から生まれた言語。

C言語は画期的な言語で、今でもOSなどのシステム開発で広く使われている。

C++は高速処理とオブジェクト指向を両立するプログラミング言語として開発された。

最初は`C with Classes`という名前で開発され、後に`C++`という名前になった。

## C with Classes

`C + Classes`

=> C言語に、クラスなどの仕組みを追加して、もっと大きなプログラムを作りやすくしようという発想

ここから、C++の特徴であるオブジェクト指向へとつながっていく。

## C++の特徴

- 高速(コンパイルしてネイティブコードを生成)
- 自由度が高い(メモリの管理など)
- オブジェクト指向

## 何使われているのか

- ゲーム開発(ゲームエンジン)
- OSやシステムソフトウェア
- ロボット・組み込みシステム
- 業務用機器のソフトウェア
