# PolicyとModel

## 概要

どうやってPolicyとModelが紐づく？

## Laravelが認識

例: TagModelとTagPolicy

```php
<?php
$this->authorize('update', $tag);
```

これで、Laravelがざっくり、

```bash
$tag は何のModel？
    |
App\Models\Tag
    |
Tagに対応するPolicyは？
    |
App\Policies\TagPolicy
    |
update() を呼ぶ
```

という処理をしてくれている。

## どこで紐づいているのか？

Model名 + Policyという命名規則に従って、Laravelが自動検出しているイメージ。

Livewireでは、

```php
<?php
$this->authorize('update', $tag);
```

としか書いていない。

=> この`$tag`に対して、`update`できるか判定して下さいと認可システムにお願いしているだけ。

## 使うときに必要なものメモ

- use宣言: ` use Illuminate\Foundation\Auth\Access\AuthorizesRequests;`
- useトレイト: `use AuthorizesRequests;`(クラス内)
- authorizeメソッド: ` $this->authorize(...);`

Livewire使用抜粋:

```php
<?php
use Illuminate\Foundation\Auth\Access\AuthorizesRequests;

class Index extends Component
{
    use AuthorizesRequests;

    ...


    public function edit(int $tagId): void
    {
        $this->openForm();

        $tag = Tag::findOrFail($tagId);

        $this->authorize('update', $tag);

        ...
```
