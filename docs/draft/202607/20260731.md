# Volt

## 概要

Volt基本要素まとめ。

## Voltとは？

Livewireコンポーネントを1ファイルで書くための仕組み。

- Blade
- PHPロジック
- Livewire

を1つのファイルにまとめることができる。

## コンポーネント作成(v4.3.0)

```bash
php artisan make:livewire sandbox.index
```

作成される:

```bash
resources/views/components/sandbox/index.blade.php
```

## 他から呼び出す

Blade:

```blade
<livewire:sandbox.index />
```

## Blade Componentとの違い

Blade Component:

```blade
<x-ui.card>
```

- UI再利用
- レイアウト
- slot
- props

=> 状態は持たない


Volt:

```blade
<livewire:like-button />
```

- UI
- State
- wire:model
- Validation
- Dispatch

=> 小さいLivewireコンポーネント
