# @classと:class

## 概要

`@class`: Blade(PHP) / `:class`: Alpine.js(JS)

## Bladeの@class()基礎

Laravel Bladeには`@class()`という便利なディレクティブがある。

```blade
@class([
    '付けたいクラス',
    '付けたいクラス',
])

<div @class([
    'bg-green-500',
    'text-white',
])>
    Dog
</div>
```

## 条件付きclass

```blade
<div @class([
    'px-4 py-2 rounded',

    'bg-green-500' => $success,
    'bg-red-500' => !$success,
])>
    結果
</div>
```
=> 状態や条件によってTailwind classを変更できる

## Alpine.jsの:class

こちらはJavaScript側。

```blade
<div x-data="{ open:false }">

    <button @click="open = !open">
        Menu
    </button>


    <div :class="open ? '' : 'hidden'">
        メニュー内容
    </div>

</div>
```

Alpineの`:class`は`x-bind:class`の省略形。

## object形式の:class

```blade
<div
    :class="{
        'bg-green-500': active,
        'bg-gray-300': !active
    }"
>
    Button
</div>
```

## どう使い分ける？

- サーバー側の状態: `@class`
- ブラウザ操作の状態: `:class`
