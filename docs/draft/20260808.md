## in_array()

PHPメソッド: ある値が配列の中に存在するか？を調べる関数。

```php
<?php

$dogs = ['john', 'pochi', 'max'];

if (in_array('john')) {
    echo 'john is in the dogs';
}
```

```php
<?php
in_array(探したい値, 配列);
```

-> 第3引数に`true`をつけた場合、型まで一致しているかチェックしてくれる
