# Route Model Binding

## 概要

URLのIDから自動でモデルを取得してくれる機能。

## 基本

```php
<?php
public function show(int $id)
{
    $post = Post::findOrFail($id);

    return view('posts.show', compact('post'));
}
```

毎回、`Post::findOrFail()`を書く。

Route Model Bindingを使うと...

```php
<?php
public function show(Post $post)
{
    return view('posts.show', compact('post'));
}
```

これだけで、Laravelが勝手に`findOrFail()`をやってくれる。

## Routeの書き方

```php
<?php
Route::get('/posts/{post}', [PostController::class, 'show']);
```

ポイントは、`{post}`と`Post $post`の名前が一致していること。

存在しないIDだったら、自動で`404 Not Fount`を返してくれる。

## メリット

- findOrFail()を書かなくてよい
- コードがシンプルになる
- 存在しないIDは自動で404を返す
- CRUDでよく使われる
