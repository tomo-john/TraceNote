# Bladeコンポーネント

## 概要

HTML部品を再利用する仕組み。

## シンプルサンプル

`resources/views/components/button.blade.php`

```blade
<button class="rounded-full px-5 py-3 bg-gray-400 text-white">
    {{ $slot }}
</button>
```

呼び出し側:

```blade
<x-button>ボタン</x-button>
```

=> ボタンの箇所が、`{{ $slot }}`に入る。

## $attributes->merge()

呼び出し元で指定したクラスと、コンポーネント側のクラスをマージする。

```blade
<button {{ $attributes->merge([
    'class' => 'rounded-full px-5 py-3 bg-gray-400 text-white w-12 h-12 inline-flex items-center justify-center'
]) }}>
    {{ $slot }}
</button>
```

呼び出し側:

```blade
<x-button class="text-lg">A</x-button>
<x-button class="text-sm">A</x-button>
```
