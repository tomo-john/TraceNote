# Livewire


## 概要


## LaravelのLivewireとは

PHPコードでサーバーとブラウザ側で非同期通信(のような動き)を実現するもの。

Livewireクラスで定義した変数(プロパティ)をBlade側とPHPクラス側で共有することができ、

ページ読み込みなしに、リアルタイムフィルタやバリデーション、モーダル表示などReactっぽいことができる。

PHPクラスとBladeだけで実装できるが、裏側ではJavaScritpなどの技術が使用されている。

- 非同期通信のような動き
    
    実際にブラウザとサーバー間で通信している

    ```bash
    ブラウザ -> リクエスト -> Livewire / Laravel -> PHPで処理
    -> レスポンス -> ブラウザの必要な部分だけ更新
    ```

- プロパティとBlade

    Livewireコンポーネントの状態(state)として管理される

- Reactっぽいことができる

    SPAのような動的なユーザー体験を、主にPHPとBladeで実装できる

## wire:modelで何が起きているのか

```blade
<input wire:model="search">
```

がるとする。

- 1. ユーザーが入力する
- 2. LivewireのJavaScriptが変更を検知
- 3. サーバーに通信する
- 4. PHP側のプロパティが更新される
- 5. Livewireコンポーネントが再評価される
- 6. 必要な画面部分をブラウザ側で更新

## つまり

Livewireは、ブラウザ側でJavaScriptを直接書かなくても、PHPとBladeを中心に動的なUIを作れるLaravelの仕組み。

ユーザー操作があると、LivewireのJSがブラウザとサーバー間の通信を行い、PHP側の状態や処理結果を画面に反映する。
