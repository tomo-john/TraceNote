# Implicit Bindin と Explicit Bindingの違い

## 概要

BindingはURLの値を、Laravelがモデルに変換してくれる仕組み。

## Implicit Bingding (暗黙的バインディング)

Laravelが自動で判断してくれる。

Route:
```php
<?php
Route::get('/posts/{post}', [PostController::class, 'show']);
```

Controller:
```php
<?php
public function show(Post $post)
{
    return view('posts.show', compact('post'));
}
```

Laravel:
```bash
{post} -> Postモデル？ -> Post::findOrFail($id)
```

を勝手にやってくれる。

## Explicit Binding (明示的バインディング)

自分で「この値からモデルを取得してね」とLaravelに教える方法。

例えば`/users/john`というURLがあるとすると、普通なら`id = 5`みたいな数値を探す。

今回は、`username = john`で検索したい。

```php
<?php
Route::bind('user', function ($value) {
    return User::where('username', $value)->firstOrFail();
});
```

と書くと、`/users/john -> username = john`で検索してくれる。

## memo

### モデル・マイグレーション

```bash
php artisan make:model Article -mcr
```

- Model
- Migration
- Controller(リソース)

### マイグレーション編集

```php
<?php
Schema::create('articles', function (Blueprint $table) {
    $table->id();
    $table->string('title');
    $table->string('slug')->unique();
    $table->timestamps();
});
```

=> `php artisan migrate`実行

### Tinkerでデータ作成

```php
<?php
Article::create([
    'title' => 'Laravel最高',
    'slug' => 'laravel-is-awesome'
]);
```

### Modelに追加

```php
<?php
protected $fillable = [
    'title',
    'slug',
];
```

### Controller

```php
<?php
public function show(Article $article)
{
    dd($article);
}
```

### Route

まずは普通に:
```php
<?php
Route::get('/articles/{article}', [ArticleController::class, 'show']);
```

=> `/articles/1`でアクセス

### モデルに getRouteKeyName() を追加

```php
<?php
public function getRouteKeyName()
{
    return 'slug';
}
```

=> `/articles/laravel-is-awesome`のアクセス
