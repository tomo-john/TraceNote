## 5. Demo

機能紹介ではなく、自分が説明した上記の設計が実際にどう動くかを見せる時間。

```
Login -> Dashboard -> Trace・Tag作成 -> Trace-Tag -> Trace-Trace -> Dashboard
```

Trace間の関連付けを実際にDemoし、知識のつながりを表現したかったことを見せる。

### Demo事前準備(構想)

- Demoは本番環境(VPS)で行う
- VPS不安定時に備え、ローカルにもデモの準備はする
- デモ用のユーザーを2名用意
    - データがなし(初めて利用する人想定)
    - データがあり(DashboardやGrowth情報の変化説明用)
- Demoデータの内容
    - 製品学習の内容は本番環境には置かない
    - VPS: TraceNote作成で実際に学んだ内容など(社外秘以外のみ)
    - ローカル: 製品学習の内容でいい素材があれば

Demoで一通りの機能を見ていただいた後パワポに戻る。
